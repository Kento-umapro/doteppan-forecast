ダイニーの日別実績を毎朝読み込んで、翌日以降60日ぶんを予測しています。係数は毎日学習し直しているので、実績が貯まるほど当たるようになります。
平常比が動くのは、祭り・展示会・コンベンションなど外の催しがあるときだけです。曜日・季節・祝日・連休・お盆は「その日の平常」の側に織り込んであります（カレンダーを見れば分かることなので要因には出しません）。祝日そのものの上振れは水準の数字に出ます。
客数は人数そのままの予測です。人員配置はこの数字で組んでください。売上の金額はこのページには出しません（平常を1.00とした指数と、普段の平均日を100とした水準だけ）。実額はダイニーで確認してください。
